# Game phases

## Pregame: Mulligan (before Turn 1)

Not part of the turn cycle below. Repeatable — the player can mulligan as
many times as they want before the game proper starts.

1. Game begins — 7 cards dealt to hand, lane starts empty (no
   auto-placed Workers).
2. Turn order is decided. For now: solo play, so the player always goes
   first. (Stubbed — real selection needs an opponent to order against.)
3. Player is asked "Are you satisfied with this hand?"
   - **Keep This Hand** — mulligan ends, game proper begins: Turn 1,
     Draw phase.
   - **Mulligan** — the *entire* current hand shuffles back into the
     deck, and a new hand is dealt with one fewer card. Back to step 3.
     Disabled once the hand is down to 1 card (the floor).

This is a Vancouver-style mulligan: no cards are individually kept or
picked — mulliganing always tosses the whole hand and costs exactly one
card per attempt.

## Turn cycle

```
Draw -> Main -> Upkeep -> Warfare -> End -> (loops to Draw)
```

- **Draw** — draw 1 card from deck to hand.
- **Main** — place 1 Worker from hand into the lane; tap untapped Workers
  in the lane to generate resources (Food or Labor).
- **Upkeep** — pay 1 Food per Worker in the lane (population). A Food
  deficit requires sacrificing that many Workers to the graveyard.
- **Warfare** — stub. No opponent is modeled yet, so this phase currently
  just passes through with a log line. Real combat/interaction design is
  a separate, future task.
- **End** — unused resources (Food, Labor) reset to 0. Untap happens here
  too, silently, as part of the End -> Draw transition — it has no
  choices, so it isn't its own UI phase.

## Design note: why Main comes before Upkeep

The original design-doc guess for turn order was
`Untap -> Upkeep -> Main -> Warfare -> End`. That doesn't work as-is here:
Upkeep needs Food, but Food is only generated by tapping Workers, and
tapping is restricted to Main. Magic: The Gathering avoids this same
problem by letting mana-producing permanents (lands) be tapped any time
the player has priority, not just during Main — so by the time Upkeep
needs mana, it's already available.

v0 takes the simpler path instead: keep tapping restricted to Main, and
move Main before Upkeep. Food is generated and spent same-turn; nothing
carries over between turns. If Upkeep-before-Main (the MTG-faithful
order) is wanted later, it requires lifting the Main-only restriction on
`TAP_WORKER` and letting Food persist across turns.

See [`src/game/types.ts`](../src/game/types.ts) for the `Phase` type and
[`src/game/engine.ts`](../src/game/engine.ts) for the reducer that
implements all of the above.
